    Settings

    YouTube proxy

    Browsers block the requests a YouTube download needs, so this page sends them through your own yt-dlp-wasm proxy. The proxy must allow this site's address.

    Your proxy URL and key stay in this browser.

    Soulseek relay

    Soulseek search and downloads go through your own secure WebSocket relay. The relay must allow this site's address.

    Your relay URL, token and Soulseek login stay in this browser.

    Leave the username and password empty to use an account this browser makes for you, like the desktop app.
